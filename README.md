## Overview

The **Student Dashboard** is a web-based front-end project designed to provide students with a centralized interface for viewing important academic and personal information.

Instead of displaying information across multiple pages, the dashboard organizes commonly required student details into a single, structured interface.

The project focuses on creating a simple yet professional user experience while applying fundamental concepts of **HTML5, CSS3, and JavaScript**.

It is also designed as a practical learning project to understand how the structure, styling, and functionality of a modern webpage work together.

---

## Key Features

| Feature | Description |
|--------|-------------|
| Student Profile | Displays essential student information in an organized format. |
| Attendance | Provides a dedicated section for attendance information. |
| CGPA | Displays academic performance information through CGPA. |
| Subjects | Presents the student's subjects in a structured manner. |
| Notices | Provides an area for important academic announcements. |
| Interactive Elements | Uses JavaScript to add interaction and dynamic behaviour. |
| Responsive Layout | Designed to maintain a clean layout across different screen sizes. |
| User-Friendly Interface | Keeps important information organized and easy to understand. |

## Technology Stack

The project is developed using the following technologies:

### Frontend

**HTML5**

Used to create the semantic structure and content of the dashboard.

**CSS3**

Used for page styling, layout, spacing, typography, visual elements, and responsive design.

**JavaScript**

Used to implement interactive behaviour and dynamic functionality.

### Development Tools

**Git**

Used for version control and tracking changes during development.

**GitHub**

Used for source-code hosting, project management, and version control collaboration.
