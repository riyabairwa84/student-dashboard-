## Overview

The Student Dashboard is a web-based front-end project designed to provide students with a centralized interface for viewing important academic and personal information.

The dashboard presents information in a clean, organized and user-friendly layout.

---

## Features

- 📊 Overall attendance overview
- 🎓 Current CGPA display
- 📚 Subject-wise attendance
- 👤 Student profile section
- 🗓️ Today's timetable
- 📝 Assignment information
- 📢 Announcements section
- 🏆 Grades section
- 📱 Responsive layout
- 🎨 Modern dashboard design
- 🧭 Easy sidebar navigation
